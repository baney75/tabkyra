60s To your first agent-driven tab

Node 20+, git and a Chromium browser: Helium, Chrome, Brave, Edge, Arc, Vivaldi or Chromium 141+. A fresh clone reached "Connected" in 45 seconds on a Mac with a warm npm cache; a cold first install takes longer.

$ git clone https://github.com/baney75/tabkyra && cd tabkyra
$ (cd cli && npm install && npm run build && npm link)
$ tabkyra setup

  1. Setup does the work. It builds the extension, registers it with every Chromium browser it finds, and offers to add Tabkyra to Claude Code and Codex. For OpenCode, Cursor and OMP it prints the config to paste.
  2. One step is yours. Browsers make you load an unpacked extension by hand. Setup shows the exact folder and waits until it connects.
  3. Ask your agent. For example: "Use tabkyra to open news.ycombinator.com and list the top five stories." If anything is off, tabkyra doctor prints the exact fix.

Your browser is signed in as you.
So you stay in command.

It asks before a new site

An agent can open only the sites you've allowed. Claude Code and Codex show the prompt inline. You can also pre-approve a site with tabkyra allow github.com.

Page text is data

Every agent is told that page content is untrusted, that it must ask you before sending, buying, posting or deleting under your sign-in, and that it never types passwords or payment details. That's guidance to the model, not a lock; the site permission is the lock.

Its own tab group

Agents work in "Tabkyra · claude" and similar groups, in background tabs. They can't see your other tabs, and their popups don't steal focus.

Nothing on the network

The browser starts a native host that talks over a Unix socket other users can't open. Only the Tabkyra extension can start it. Programs running as you can reach it, as they can your shell.

How it works

Each agent session gets its own tab group, and it survives extension reloads, so a harness that reconnects lands back on its own tabs. Screenshots and input go through chrome.debugger, which works on hidden tabs, so your window never has to be in front.
